# PyMint | Premium M.Tech Project Solutions

PyMint is a modern, responsive web application and landing page designed for premium M.Tech project solutions, specializing in Python-powered web apps, interactive portfolios, transparent student-budget pricing, and streamlined academic delivery.

## Features ✨

* **Cyberpunk Neon Aesthetic**: Built with a sleek dark-mode layout, neon color accents, and subtle glowing components.
* **Dynamic Floating Icons**: Animated floating technical background icons for Python, React, JavaScript, and databases.
* **Interactive Project Portfolio**: Showcases a grid of Python-based applications including AI Research Assistants, Smart Attendance Systems, and Data Dashboards.
* **Transparent Pricing & Contact Portal**: Features structured pricing cards for student projects alongside a responsive inquiry form with animated feedback states.
* **Smooth Scrolling & Scroll Animations**: Custom scrollbar styling, smooth anchor transitions, and scroll-triggered fade-in animations.

## Technology Stack 🛠️

* **Markup**: HTML5
* **Styling**: CSS3 (Flexbox, CSS Grid, Custom Variables, Keyframe Animations)
* **Scripting**: Vanilla JavaScript (Scroll Observers, Form Handling State Simulator)
* **Icons & Fonts**: FontAwesome 6, Google Fonts (*Poppins*)

## Getting Started 🚀

1. Save the code locally as `index.html`.
2. Ensure your logo (`pymint.png`) or remote asset references are linked properly.
3. Open `index.html` directly in any modern web browser to view the platform.
